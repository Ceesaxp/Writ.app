Writ

Native macOS Markdown editor

Install

Drag the Writ icon onto the Applications folder. That’s it.

Use

Open any .md / .markdown file from Finder, or use File › Open… (⌘O) inside Writ. The window splits source on the left, rendered preview on the right; toggle with View › Source / Preview / Split (⌥⌘1 / ⌥⌘2 / ⌥⌘3).

Format shortcuts

⌘BBold
⌘IItalic
⌘UStrikethrough
⌘`Inline code
⌘KLink
⌘1 – ⌘6Headings 1 – 6 (toggle)
⇧⌘KFenced code block
⇧⌘7Ordered list
⇧⌘8Unordered list
⇧⌘.Block quote

First launch

The DMG is signed with a Developer ID and notarized, so macOS Gatekeeper opens it without complaint. If you see a warning anyway, right-click Writ in /Applications and choose Open once.

Local-first

Nothing in Writ phones home. KaTeX, Mermaid, and highlight.js are all bundled and rendered offline. Your documents stay on disk.
